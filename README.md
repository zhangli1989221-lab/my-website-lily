# Zhang Li Portfolio Upload Package

This folder contains the latest static website package for GitHub upload.

Upload everything in this `new` folder to your GitHub repository:

- `index.html`
- `assets/`
- `portfolio/`

For GitHub Pages:

1. Create or open a GitHub repository.
2. Upload all files and folders from this directory to the repository root.
3. Go to `Settings` -> `Pages`.
4. Set `Source` to `Deploy from a branch`.
5. Choose the branch, usually `main`, and folder `/root`.
6. Save and wait for GitHub Pages to publish.

The generated page uses relative asset paths, so it can work under a GitHub Pages repository path.
